# TSAAK V9 Heavy Demo

Routes principales:
- /demo : mode d'emploi de la démo
- / : home + 5 castes
- /media : dashboard Media
- /wanted : création Wanted
- /intermediaires : dashboard Intermédiaires
- /intermediaires/respond : réponse au Wanted
- /media/proposals : réponses reçues par le Media
- /talent : dashboard Talent + acceptation
- /search : recherche IA de Talents
- /shortlist : multi-message
- /help-me : Help Me
- /organisation : dashboard Organisation
- /communaute : dashboard Communauté
- /contracts : contract builder

La simulation utilise localStorage, donc aucun backend n'est requis.
